核心功能

把想法留在任何网页

Momo Notes 是长在浏览器里的便利贴，随手记、随手存。

  • 一键创建便利贴

    点击工具栏图标，新建一张便利贴，想到就写。

  • 自由拖动位置

    按住顶部标题栏拖动，放到网页任意角落。

  • 四种柔和配色

    粉色、奶黄、薄荷绿、薰衣草紫，随心情切换。

  • 自动保存笔记

    输入即保存，刷新页面、重启浏览器也不丢。

  • 不同网页独立记录

    每个网页各有一套便利贴，互不串扰。

  • 本地存储，保护隐私

    数据只留在你的浏览器里，不上传、不联网。

安装指南

用开发者模式安装

Momo Notes 目前通过 Chrome 的「加载已解压的扩展程序」安装，步骤如下。

  1. 1

    下载 ZIP 压缩包

    点击下方「下载 Momo Notes」按钮，获取 momo-notes.zip 压缩包。

  2. 2

    解压到本地文件夹

    把 ZIP 解压到一个固定目录，例如 D:\momo-notes。

  3. 3

    打开 chrome://extensions

    在 Chrome 地址栏输入 chrome://extensions 并回车。

  4. 4

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  5. 5

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择刚才解压的文件夹，即可开始使用。
